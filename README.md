## 📈 Complexity Analysis

Each important solution includes, where applicable:

* **Time Complexity**
* **Space Complexity**
* **Approach / Explanation**

Example:

```python
def linear_search(arr, target):
    for i in range(len(arr)):
        if arr[i] == target:
            return i
    return -1
```

**Time Complexity:** `O(n)`
**Space Complexity:** `O(1)`
